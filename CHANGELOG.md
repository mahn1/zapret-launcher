# Изменения

## 1.0.0 — 2026-10-28

Первый публичный релиз.

- Запуск и остановка winws.exe с выбранной стратегией `general*.bat`, без консольного окна, вывод в журнал.
- Проверка связи с YouTube и Discord во время включения и раз в 30 секунд, таймер работы.
- Автоподбор стратегии: перебор всех `general*.bat` с проверкой связи и выбором лучшей.
- Служба Windows: установка и удаление через оригинальный `service.bat`.
- Автозапуск с Windows в трей (Планировщик задач), автовключение обхода, сторож (перезапуск winws, предупреждение о потере связи).
- Свои сайты: обход и исключения, быстрые наборы Roblox (картинки) и Photon (с Game Filter).
- Обновление zapret с GitHub (только `github.com/Flowseal/zapret-discord-youtube`, только по кнопке) с сохранением пользовательских списков.
- Telegram: поиск MTProto-прокси с проверкой настоящим рукопожатием, подключение через `tg://proxy`.
- Трей, тёмная тема, анимации; один exe ~190 КБ на встроенном .NET Framework 4.8.
